# 制作参数参考

使用本技能时，以用户提供并确认的角色图、声音与字幕位置为准。将素材位置配置到当前项目，不依赖特定电脑路径。

## 最新字幕参数

2026-10-01“画面清理瘦长字幕版”采用：
- 字体：PingFang SC Light，渲染名称 `PingFangSC-Light`
- 字号：120（1080×1920 画布）
- 水平缩放：78%；垂直缩放：110%；逐字竖排间距约 116 像素
- 黑色、非粗体；描边 0、阴影 0；无标点
- 大全景字幕中心：(510,1065)
- 本我近景字幕中心：(890,650)
- 自我近景字幕中心：(200,930)

参数是本节目起点，须结合短语长度与实际画面检查。不要因字体文件名包含 Light 就假定渲染正确，抽帧确认细黑字形；勿沿用旧 Kaiti SC 和白边字幕。

## 干净构图实例

旧 v5 本我镜头右侧与右下角有截断的白色线条前景。近期处理：从 1080×1920 画面取左上方 900×1600 区域，再等比放大到竖屏尺寸。此参数只适用于该素材；新镜头须重新检查边界、脸部与字幕位置，不能固定套裁切。


## 角色素材配置

每个项目准备：本人参考图、本我仰望近景、自我雾白无眼镜近景、两人大全景及三种字幕位置参考图。保留用户认可的原图，不把照片、声音和视频存入技能仓库。

## 声音与时间表

本地生成两条角色干声线与逐句干声；声音空间感在后期完成。对白时间表保留原素材时间、调整后的对白时间和镜头起点。声音速度或停顿变化时同步调整视频和字幕。
