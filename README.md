# 华嗲自我对话制作技能

用于制作、修改或复盘“实体本我与巨大雾白自我”的竖屏心理对话短视频。

## 包含什么

- 声音先行：本地配音 → 确认声音 → HeyGen 音频驱动画面 → 本地剪辑、字幕与混音
- 本我近景画面边缘清理规范
- 瘦长细黑竖排字幕，无白边、无标点
- 角色一致性、缓慢推拉、空间声音及结尾过渡要求

## 在 Codex 使用

下载Releases中的发行版本包。

将下载好的zip放到本机技能目录中，在对话中指定 `$huadia-self-dialogue`。例如：

> 请用 $huadia-self-dialogue 制作一期自我与本我的对话样片

首次使用时提供或指定已确认的角色图和声音资源。按每次任务授权使用外部工具。

本仓库只包含技能说明，不包含私人照片、配音、视频、字体文件或账号凭据。
